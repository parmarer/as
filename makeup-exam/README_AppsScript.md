# วิธีสร้าง Google Form จากโค้ด Apps Script

## ไฟล์ในโฟลเดอร์นี้
| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | โค้ด Apps Script พร้อมใช้ (มีข้อสอบฝังอยู่ในตัวแปร `EXAM`) |
| `appsscript.json` | ไฟล์ตั้งค่าโปรเจ็กต์ (ไม่บังคับ) |
| `exam_items.json` | ข้อสอบต้นฉบับ (แหล่งข้อมูลเดียวของข้อสอบ) |
| `draft_makeup_exam.docx / .md` | ร่างข้อสอบพร้อมเฉลยสำหรับตรวจทาน |
| `tools/` , `tests/` | ตัวสร้าง `Code.gs` และตัวทดสอบด้วย Google Forms จำลอง |

## ขั้นตอนการใช้งาน
1. เปิด <https://script.google.com> ด้วยบัญชี Google ที่จะเป็นเจ้าของแบบฟอร์ม แล้วเลือก **โปรเจ็กต์ใหม่**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ของโปรเจ็กต์ แล้ววางโค้ดจากไฟล์ `Code.gs` ในโฟลเดอร์นี้ทั้งหมด
3. เลือกฟังก์ชัน **`createMakeupExamForm`** ในแถบเครื่องมือ แล้วกด **เรียกใช้** (ครั้งแรกระบบจะขออนุญาตเข้าถึง Google Forms)
4. เปิด **บันทึกการดำเนินการ (Execution log)** เพื่อดูลิงก์แก้ไขและลิงก์ให้นักเรียนตอบ
5. เปิดแบบฟอร์ม ตรวจ **Settings → Quizzes → Release grade** ให้ตรงกับที่ต้องการ (ผู้เขียนโค้ดไม่ได้กำหนดค่านี้จากสคริปต์)

> การรันซ้ำจะสร้างแบบฟอร์มใหม่ทุกครั้ง ไม่แก้ฟอร์มเดิม

## ค่าที่ปรับได้ (ตัวแปร `CONFIG` ต้นไฟล์)
| ค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `COLLECT_EMAIL` | `true` | เก็บอีเมลผู้ตอบ |
| `ADD_STUDENT_INFO` | `true` | เพิ่มส่วน "ข้อมูลผู้เข้าสอบ" ไว้ต้นแบบฟอร์ม (ดูหัวข้อถัดไป) |
| `ADD_FEEDBACK` | `false` | แสดงเหตุผลเฉลยให้นักเรียนหลังตรวจ |
| `SHOW_PROGRESS_BAR` | `true` | แสดงแถบความคืบหน้า |

## ข้อมูลนักศึกษาที่เก็บ
ส่วน "ข้อมูลผู้เข้าสอบ" อยู่ต้นแบบฟอร์ม กำหนดไว้ในตัวแปร `STUDENT_FIELDS` ต้นไฟล์ `Code.gs`

| ช่อง | รูปแบบ | บังคับ | การตรวจรูปแบบ |
|---|---|---|---|
| ชื่อ-สกุล | พิมพ์เอง | ใช่ | ไม่ต้องใส่คำนำหน้าชื่อ |
| เลขประจำตัว | พิมพ์เอง | ใช่ | ตัวเลข 5-15 หลัก (`[0-9]{5,15}`) |
| คณะ/วิทยาลัย | พิมพ์เอง | ใช่ | - |
| สาขาวิชา | พิมพ์เอง | ใช่ | - |
| ชั้นปี | เลือกจากรายการ (ปีที่ 1-4, สูงกว่าปีที่ 4) | ใช่ | - |
| กลุ่มเรียน (Section) | พิมพ์เอง | ไม่ | - |

วิธีปรับ
- **เพิ่ม/ลบช่อง:** แก้รายการใน `STUDENT_FIELDS` (แต่ละช่องมี `title`, `required`, `choices`, `pattern`, `help`)
- **ให้เลือกสาขาวิชาจากรายการ:** ใส่ชื่อสาขาใน `choices` ของช่อง "สาขาวิชา" เช่น `choices: ['สาขา ก', 'สาขา ข']` ช่องจะเปลี่ยนเป็น Dropdown ซึ่งช่วยให้ชื่อสาขาสะกดตรงกันเมื่อรวมข้อมูล
- **รูปแบบเลขประจำตัว:** ค่าเริ่มต้นรับเฉพาะตัวเลข 5-15 หลัก หากเลขประจำตัวของสถาบันมีตัวอักษรหรือเครื่องหมาย ให้แก้ `pattern` หรือลบบรรทัด `pattern` ออก มิฉะนั้นนักศึกษาจะกรอกไม่ผ่าน
- **ปิดส่วนนี้:** ตั้ง `ADD_STUDENT_INFO: false`
- ข้อความชี้แจงการใช้ข้อมูลอยู่ใน `STUDENT_SECTION.help` ควรปรับให้ตรงกับนโยบายคุ้มครองข้อมูลส่วนบุคคลของสถาบัน
- ข้อมูลที่กรอกจะรวมอยู่กับคำตอบแต่ละรายในแท็บ **Responses** ของแบบฟอร์ม และเชื่อมต่อกับ Google Sheets ได้จากปุ่ม "Link to Sheets" ในแท็บเดียวกัน

## โครงสร้างแบบฟอร์มที่สร้าง
- โหมดแบบทดสอบ (Quiz) ไม่สลับลำดับข้อ
- ส่วนข้อมูลผู้เข้าสอบ (6 ช่อง)
- ตอนที่ 1: เลือกตอบ 24 ข้อ ข้อละ 1 คะแนน จัดกลุ่มตามหัวข้อ 6 หัวข้อ พร้อมเฉลยในฟอร์ม
- ตอนที่ 2: เขียนตอบสั้น 3 ข้อ ข้อละ 2 คะแนน (บังคับตอบเป็นตัวเลข)
- คะแนนเต็ม 30 คะแนน

## ข้อเขียนตอบสั้น: การให้คะแนน
Apps Script ไม่สามารถกำหนดเฉลยให้ข้อเขียนตอบสั้นในแบบฟอร์มได้โดยตรง มี 2 ทางเลือก
1. **ใช้ฟังก์ชันช่วย** หลังนักเรียนส่งคำตอบแล้ว ให้เรียก `gradeShortAnswers()` ในโปรเจ็กต์เดิม สคริปต์จะเทียบคำตอบกับเฉลยและบันทึกคะแนน (รองรับเลขไทย และ `,` เป็นจุดทศนิยม เช่น ๓๙ หรือ 0,08)
2. **ตั้งเฉลยด้วยมือ** ในหน้าแก้ไขฟอร์ม (3 ข้อ) โดยเลือก "Answer key" ของแต่ละข้อ
   เฉลยของข้อ 25-27 คือ **19**, **39**, **0.08**

## การสลับตัวเลือก
Apps Script ไม่มีคำสั่งสลับลำดับตัวเลือกของข้อเลือกตอบ หากต้องการให้สลับ ต้องเปิด "Shuffle option order" ในแต่ละข้อด้วยมือ ตัวเลือกในฟอร์มไม่มีตัวอักษร ก-ง นำหน้า จึงสลับได้โดยไม่กระทบเนื้อหาข้อสอบ

## การแก้ข้อสอบแล้วสร้างโค้ดใหม่
1. แก้ `exam_items.json`
2. รัน `python3 tools/build_code_gs.py` ในโฟลเดอร์นี้ (จะเขียนทับ `Code.gs`)
3. รัน `node tests/mock_formapp_test.js` เพื่อตรวจโครงสร้างด้วย Google Forms จำลอง

## สถานะการทดสอบ
- ตรวจไวยากรณ์ JavaScript และทดสอบด้วย Google Forms จำลองผ่านทั้งหมด (จำนวนข้อ ตัวเลือก ตำแหน่งเฉลย คะแนนรวม 30 และตรรกะของ `gradeShortAnswers`)
- **ยังไม่ได้รันบน Google จริง** เพราะสภาพแวดล้อมนี้เข้าถึงบัญชี Google ของผู้ใช้ไม่ได้ ควรรัน `createMakeupExamForm` หนึ่งครั้งแล้วเปิดดูฟอร์มก่อนใช้งานจริง โดยเฉพาะ `gradeShortAnswers()` ซึ่งเป็นส่วนที่ควรทดลองกับคำตอบทดสอบก่อน
